# Phase 2b.2 Candidate Cloud Read Path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在通过候选人云端回填和严格一致性校验后，将 `candidates` 表安全切换为候选人读取权威源，同时保留 `workspace_state` 回退能力和本地简历大字段。

**Architecture:** `candidate-repo.js` 负责候选人行的无损映射和分页读取；新的纯函数模块负责一致性报告、闸门判断和权威候选人集合构造；`index.html` 只负责编排迁移、校验、启用、启动拉取和持久化。切换前继续双写，切换后候选人行写入成为同步成功的必要条件。

**Tech Stack:** Vue 3 IIFE、Supabase PostgREST、IndexedDB 快照、Node.js `node:test`、PostgreSQL/RLS。
