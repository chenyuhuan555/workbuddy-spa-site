# 负责人多人筛选与智能评估报告设计

## 目标

1. 允许公司、岗位、候选人的负责人字段包含多个负责人，并让负责人筛选按姓名拆分匹配。
2. 将 AI 工具箱的长文本结果转换为猎头可快速扫描的“智能评估报告”卡片。

## 方案

- 保持现有 `owner` 字段兼容，不新增数据库迁移；多人值使用逗号、顿号、斜杠或换行分隔。
- 负责人列表展示原始多人值；筛选使用统一的负责人分词函数，任一姓名命中即可返回记录。
- AI 报告保留原始内容，展示层从 Markdown 标题、列表和 Mermaid 代码中提取核心判断、优势、推荐话术、风险、待确认和人才画像/能力结构。
- 结果默认只展示摘要，长文本使用“展开查看更多”；顶部只保留保存、复制和更多操作。
- 无法可靠识别的字段显示“待评估/待确认”，不编造分数或事实。

## 验证

- 单元测试覆盖多人负责人拆分、公司/岗位/候选人筛选命中和报告结构化字段。
- 生产构建与完整测试通过后部署 GitHub Pages，并验证线上页面包含新文案。
