# WorkBuddy 工作台公司招聘漏斗首页设计

## 目标

将工作台首页重构为以“公司招聘漏斗”为第一视觉核心的轻量 SaaS 工作区。领导进入首页后应在第一屏看清当前公司的候选人规模、推进阶段、阶段转化与渠道构成；顾问在下方继续处理今日待办并完成今日复盘。

本轮只调整页面信息层级、布局、样式和交互呈现，不修改现有业务逻辑、数据结构、权限判断、筛选口径或路由行为。

## 页面结构

首页保留现有顶部导航和左侧导航。工作区采用暖白背景 `#FAFAF8`，左右内边距为 24–32px，模块间距为 16–20px。

主要内容分为两层：

1. 第一层为公司招聘漏斗大模块，内部使用约 70% / 30% 的两列布局：左侧六阶段横向 Pipeline，右侧渠道来源。
2. 第二层为今日执行区域，使用约 65% / 35% 的两列布局：左侧今日待办，右侧今日复盘。

模块使用白色背景、`#E9ECEA` 边框和 12px 圆角。阴影仅在需要区分层级时使用极轻效果，不使用大面积渐变或厚重卡片。

## 顶部与筛选

顶部导航保持约 64px，并继续保留工作台标题、全局搜索、新建按钮、用户头像和左侧导航。

公司漏斗标题展示为“当前公司名称 · 公司招聘漏斗”。标题区域继续使用现有日期、公司、岗位、顾问筛选和刷新能力。筛选器统一为 36–38px 高的轻量描边下拉框；刷新使用 SVG 图标；渠道导入和新增人才沿用现有入口，不增加重复按钮。

## 公司招聘漏斗

### 阶段

六个阶段保持单行，不换行：

`新增人才 → 已查看 → 已触达 → 有意向 → 已推荐 → 进入面试`

每个阶段展示：

- 现有阶段名称。
- 语义一致的轻量 SVG 图标。
- 当前真实人数，字号 28–32px。
- 相对于新增人才的占比。

阶段之间使用细 SVG 箭头连接。每个阶段继续绑定现有 `openHomeFunnelCandidates(stage)`，点击后进入人才库并带入原有筛选。

### 转化率

相邻阶段之间展示阶段转化率，依次对应查看率、触达率、意向率、推荐率和面试率。转化率根据现有阶段人数计算；分母为零时显示 `—`，不制造百分比。

漏斗底纹只提供非常轻的面积趋势感，不承载额外数据，也不引入图表依赖。

### 经营指标

漏斗底部使用三个等宽轻量指标：

- 总体转化率：进入面试人数 / 新增人才人数。
- 较上周同期：仅在现有数据能够计算时显示真实结果，否则显示 `—`。
- 本期新增：使用当前日期筛选范围内的新增人才数，并保持现有筛选口径。

## 渠道来源

渠道来源与漏斗位于同一大模块右侧。每一项展示渠道名称、人数、相对最大渠道的横向进度条和占比。主渠道使用品牌绿色，零数据渠道使用浅灰色。

“查看新增人才”继续进入对应人才列表；渠道行和导入入口继续复用 `openHomeFunnelChannelDetails` 与 `openHomeFunnelChannelImport`。不把参考图中的“倍罗”等示例名称写入数据。

## 今日待办

今日待办使用紧凑表格，不使用大 KPI 卡片。标题展示待办总数，Tab 使用现有待办数据映射为全部、待触达、待反馈、待推荐、待面试的轻量筛选呈现。

每行展示候选人、公司 / 岗位、当前状态、下一步动作和截止时间。状态标签仅做前端视觉映射：待触达为浅橙、待反馈为浅蓝、待推荐为浅紫、待面试为浅绿；不创建新的业务状态。

点击待办继续调用现有 `openTodoDetail(todo)`；“查看全部”和“新增待办”继续调用现有入口。无待办时保留简洁空状态，不显示空表头。

## 今日复盘

今日复盘展示新增人才、触达、有意向、已推荐和进入面试五项真实数据。数据全部来自现有漏斗阶段汇总。

“AI 智能总结”在本轮不新增接口或持久化字段。优先展示已有分析结果；没有现成分析结果时，根据当前真实指标生成一段确定性的前端摘要。摘要只描述可计算事实，不虚构环比或建议依据。

“今天遇到的问题”和“明日重点”使用两个并列的小型编辑区域。默认展示 placeholder，聚焦后进入编辑状态，继续复用现有 `homeReviewNotes` 绑定。

## 导航视觉

左侧导航不改变菜单结构、权限或点击行为。当前页面使用极浅绿色背景，其他菜单透明，悬停使用极浅灰绿色；图标与文字间距保持一致。底部账户区域保持透明、扁平，不恢复独立卡片感。

## 响应式

- 1920px 和 1600px：完整呈现 70% / 30% 漏斗区与 65% / 35%执行区。
- 1440px：六阶段仍保持单行，通过收紧阶段间距与图标尺寸适配，不降低正文可读性。
- 更窄桌面宽度：允许漏斗内部横向滚动，不将六阶段折行。
- 较窄屏幕：待办与复盘可以上下排列，业务内容与操作入口不隐藏。

## 数据与错误状态

- 所有数字继续来自 `homeFunnelDashboard`、`homeFunnelStageSummary`、`dashboardTodos` 和现有公司 / 岗位 / 顾问数据。
- 加载和错误状态继续复用现有控制器状态。
- 缺失数据使用 `—` 或现有空状态，不写入参考图中的示例候选人、渠道、人数或转化率。
- 不新增 Candidate、Application、Recommendation、Todo 或 Funnel 数据字段。

## 测试与验收

1. 首页第一屏以公司招聘漏斗为最大模块，渠道来源位于右侧。
2. 六个阶段在 1440px 下保持单行，阶段人数、占比和相邻转化率清晰可读。
3. 漏斗阶段、渠道、待办、查看全部、新增待办和导入人才仍调用原有入口。
4. 无上一周期数据时“较上周同期”显示 `—`。
5. 今日待办有数据时显示紧凑表格，无数据时显示空状态。
6. 今日复盘使用真实漏斗汇总，人工复盘字段仍可编辑。
7. 左侧导航只发生样式变化，菜单结构、权限和账号交互不变。
8. 静态 UI 回归测试、完整 `npm test` 和生产构建通过。
9. 在真实浏览器中检查 1440px、1600px 与 1920px 宽度下的布局、控制台和点击入口。

## 非目标

- 不重构现有漏斗服务、事件仓库或状态模型。
- 不新增 AI 服务调用、图表库、后端接口或数据库迁移。
- 不修改人才库表格、推进中心、公司页或其他模块的业务 UI。
- 不写入参考图中的任何示例业务数据。
