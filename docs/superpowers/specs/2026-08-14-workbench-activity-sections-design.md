# 工作台首页三段式工作区视觉设计

## 目标

将首页的“渠道漏斗 / 今日待办 / 今日复盘”统一为参考图所示的轻量工作区：白底、细分隔线、明确留白、绿色数字与状态强调，减少传统 Dashboard 的卡片感。

## 范围

- 只调整首页三个区域的布局、间距、字号、分隔线和图标表现。
- 保留现有渠道漏斗、渠道来源、待办、复盘统计和点击跳转逻辑。
- 保留待办的空状态、新增待办入口、筛选统计和表格数据绑定。
- 下拉箭头、日期、逾期状态和查看全部使用 SVG 图标。
- 漏斗最后一行保留与转化率相同的占位列，确保数字纵向对齐。
- 待办日期区域固定为“图标列 + 文本列”，确保三行图标对齐。
- 顶部内容增加留白，避免标题贴近页面上沿。

## 非目标

- 不新增数据模型、字段或统计口径。
- 不修改人才库、推进中心、AI 应用中心或知识库页面。
- 不改变现有权限判断、持久化、筛选、分页和路由行为。

## 验收标准

1. 三个区域使用统一的白底、浅灰分隔线和间距体系。
2. “进入面试”数字与其他漏斗数字在同一列。
3. 待办中的日历图标和逾期时钟图标在同一列，文字在同一列。
4. 页面不出现文字下三角、方块日期符号或文字时钟符号。
5. 现有 UI 测试、完整测试和生产构建通过。
