# 人才库视觉精简设计

## 目标

在上一版 Excel 化人才库基础上，把页面第一视觉重心收敛到人才数据表本身，形成偏 Notion Database、Linear Table 的桌面端高信息效率体验。

## 已确认的界面方案

- 顶部区域压缩为一条工具栏：页面标题、人才库专属搜索、自定义列、更多筛选、新增人才集中在同一行。
- 删除人才库页面重复的大搜索入口，不改变全局搜索能力之外的人才库专属搜索。
- 默认筛选只展示入库时间、归属顾问、流程阶段等高频项，其余筛选进入“更多筛选”。已选条件以 Filter Chip 展示。
- 保留上一版人才库现有默认列集合，不减少默认列数量；“自定义列”继续用于打开其他字段。
- 相关字段在既有列体系中采用上下两行展示：Base、薪酬、当前公司/岗位分别显示当前值与期望值或岗位副信息。
- 姓名列保持左侧 sticky；操作列只保留“···”入口。
- 桌面端优先：页面标题约 28–30px，姓名 16px/600，正文 15px，次级信息 13px，表头 13–14px，行高约 58–64px。
- 背景使用干净灰白色，表格使用白色，减少边框、阴影和圆角；品牌绿色只用于主要按钮、选中状态和少量强调。
- 移除人才库背景中的大面积绿色模糊光影。

## 数据与行为边界

- 不修改候选人、岗位、推进关系的写入语义。
- 不改变候选人详情抽屉、全页详情、筛选逻辑和分页逻辑；只调整展示顺序、视觉分组与默认列呈现。
- 现有自定义列状态继续兼容，缺省或旧状态不应导致表格空列或运行时错误。

## 验证

- 新增静态回归检查覆盖工具栏整合、重复搜索入口移除、默认列不减少、筛选 Chip、字体/行高/字段双行展示、sticky 姓名列和“···”操作列。
- 运行人才库相关测试、全量测试、生产构建，并检查预览页面。
